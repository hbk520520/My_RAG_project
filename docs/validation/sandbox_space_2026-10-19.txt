SPACE-specific offline coverage (tests/test_space_sandbox.py, 44 tests)
----------------------------------------------------------------------
- Default Docker backend and explicit invalid-backend rejection.
- Disabled/invalid SPACE configuration fails without fallback.
- Digest-pinned template and network-isolation verification-record checks.
- Explicit SPACE vCPU/memory/disk units, no Docker quota reinterpretation.
- Normal create -> operation -> running -> process-ready -> command -> SSE ->
  exit -> delete lifecycle.
- stdout fallback, multiline/fragmented SSE, code exception, nonzero exit,
  create failure, readiness timeout, output limit.
- Missing exit event, error/resync frames, corrupt frames, stream interruption.
- Partial create response with a known sandbox id still cleans up; command
  responses naming another sandbox and exit events naming another process are
  rejected.
- Attachment requires authorization_header transport and a valid, unexpired
  expiry; malformed or expired attachments fail closed.
- Cleanup failure does not overwrite a successful result; unknown handle does
  not delete another task's sandbox; cleanup from another run is refused.
- A SPACE handle is one-shot: a second command is refused instead of sharing a
  guest workspace.
- Real SQLite effects ledger: original idempotency key/method/path/body survive
  a lost create/command response; create/command/delete intents remain after a
  successful run; the response update does not extend the idempotency window;
  tokens are absent; retry is blocked.
- Cancellation rejects a late result while independent cleanup still runs.
- Epoch change rejects reuse of an old handle; task/project ownership checks
  protect cleanup.
- Idempotency-window expiry, deployment/API-origin/template mismatch and
  changed method/path/body are rejected; token rotation does not change the run
  pin identity.
- Embedded runner contract executed locally through Python subprocess.
- Standard-library transport reads a loopback response and does not follow a
  302 redirect.
